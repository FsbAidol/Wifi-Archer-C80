# Wifi-Archer-C80

Telegram-бот для управления роутером **TP-Link Archer C80** (аппаратные версии **1.0** и **2.20**).

Бот позволяет из Telegram смотреть состояние роутера, список устройств, включать/выключать
Wi-Fi по диапазонам и перезагружать устройство. Доступ разрешён только заранее заданному
списку Telegram User ID — все остальные получают «Доступ запрещён».

---

## Возможности

| Команда | Действие |
|---|---|
| `/start`, `/help` | Справка по командам |
| `/myid` (или `/id`) | Показать ваш Telegram User ID (для `ADMIN_IDS`) |
| `/status` | Сводный статус: WAN/LAN IP, аптайм, клиенты, состояние Wi-Fi + панель управления |
| `/info` | Модель, аппаратная версия (1.0 / 2.20) и версия прошивки |
| `/ip` | Подробные сетевые параметры (маска, шлюз, DNS, тип WAN) |
| `/devices` | Список подключённых устройств |
| `/leases` | Аренды DHCP |
| `/wifi` | Панель управления Wi-Fi (кнопки 2.4 / 5 GHz) |
| `/wifi_on 2g\|5g` | Включить основную сеть диапазона |
| `/wifi_off 2g\|5g` | Выключить основную сеть диапазона |
| `/reboot` | Перезагрузка роутера (с подтверждением кнопкой) |
| `/ping <host>` | Проверить доступность хоста с машины, где запущен бот |

Inline-кнопки на панели Wi-Fi показывают текущее состояние и выполняют противоположное
действие; перезагрузка запрашивает подтверждение, чтобы её нельзя было запустить случайно.

---

## Стек

- **Python 3.10+**
- **[aiogram](https://aiogram.dev/) 3.x** — асинхронный фреймворк Telegram Bot API
- **[tplinkrouterc6u](https://pypi.org/project/tplinkrouterc6u/)** — клиент роутеров TP-Link
  (класс `TplinkC80Router`)
- **[python-dotenv](https://pypi.org/project/python-dotenv/)** — загрузка конфигурации из `.env`

Клиент роутера синхронный (построен на `requests`), поэтому каждый запрос к роутеру
выполняется в отдельном потоке через `asyncio.to_thread` и не блокирует event loop aiogram.

## Установка и настройка

### 1. Установите зависимости

Рекомендуется виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Создайте бота и получите токен

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → следуйте подсказкам.
2. Скопируйте выданный токен вида `123456789:AA...`.

### 3. Узнайте свой Telegram User ID

Он нужен для белого списка `ADMIN_IDS`. Способы:

- напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш ID;
- или запустите бота и отправьте ему `/myid` (см. шаг 5) — но для первого запуска
  добавьте в `ADMIN_IDS` любой ID и поправьте позже.

### 4. Заполните конфигурацию

```bash
cp .env.example .env
```

Откройте `.env` и заполните как минимум:

```dotenv
BOT_TOKEN=123456789:AA_ваш_реальный_токен
ADMIN_IDS=111111111,222222222     # ваши Telegram User ID через запятую
ROUTER_HOST=192.168.0.1           # адрес веб-интерфейса роутера
ROUTER_PASSWORD=пароль_админа_роутера
```

> **Важно.** Бот должен запускаться в той же сети, где доступен роутер
> (обычно локальная сеть 192.168.0.x). Из «облака» без VPN до роутера не достучаться.

Полный список переменных — в [`.env.example`](.env.example). Кратко:

| Переменная | Обяз. | По умолч. | Описание |
|---|:--:|---|---|
| `BOT_TOKEN` | ✅ | — | Токен бота от @BotFather |
| `ADMIN_IDS` | ✅ | — | Telegram User ID админов через запятую/пробел |
| `ROUTER_HOST` | ✅ | — | Адрес роутера, напр. `192.168.0.1` |
| `ROUTER_PASSWORD` | ✅ | — | Пароль администратора веб-интерфейса |
| `ROUTER_USERNAME` | | `admin` | Логин веб-интерфейса |
| `ROUTER_VERIFY_SSL` | | `true` | Проверять SSL-сертификат (для HTTPS с самоподписанным — `false`) |
| `ROUTER_TIMEOUT` | | `15` | Таймаут запроса к роутеру, сек |
| `ROUTER_SESSION_TTL` | | `600` | Сколько секунд переиспользовать сессию (`0` — каждый раз заново) |
| `PING_COUNT` | | `4` | Число пакетов в `/ping` |
| `LOG_LEVEL` | | `INFO` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `LOG_FILE` | | `bot.log` | Путь к файлу лога |
| `LOG_TO_CONSOLE` | | `true` | Дублировать логи в консоль |

Файл `.env` содержит секреты и уже добавлен в `.gitignore` — не коммитьте его.

### 5. Запустите бота

```bash
python bot.py
```

При старте бот:

- проверяет конфигурацию (при ошибке печатает понятный список проблем и выходит с кодом `2`);
- настраивает логирование в `bot.log` (с ротацией) и, опционально, в консоль;
- заполняет меню команд в Telegram и запускает long polling.

Остановка — `Ctrl+C`.

## Безопасность

- **Белый список.** Обработчики закрыты middleware `AccessMiddleware`: событие
  обрабатывается, только если `from_user.id` есть в `ADMIN_IDS`. Остальные получают
  «🚫 Доступ запрещён», а попытка пишется в `bot.log` вместе с user id и username.
- **Секреты** читаются исключительно из окружения/`.env`, в коде их нет.
- **Данные с роутера** (имена устройств, SSID) экранируются перед выводом в HTML-режиме.
- **`/ping`** выполняется списком аргументов (без shell), цель проверяется регулярным
  выражением — инъекции команд исключены.
- **Перезагрузка** требует явного подтверждения кнопкой.

---

## Логирование

Логи пишутся в `bot.log` рядом с `bot.py` (уровень и путь настраиваются через `LOG_LEVEL`
и `LOG_FILE`). Файл ротируется: при достижении 1 МБ создаётся `bot.log.1` … `bot.log.5`.

## Тесты

Тесты не требуют реального роутера или подключения к Telegram: клиент роутера и сессия
Telegram подменяются заглушками.

```bash
pip install pytest pytest-asyncio
python -m pytest -q
```

Покрыто: разбор конфигурации, логика `RouterManager` (ленивое подключение, кэш сессии,
повтор при сетевой ошибке, маппинг исключений), форматирование, middleware доступа,
обработчики команд и callback'ов, а также сквозной прогон реального `Update` через
настоящий `Dispatcher` aiogram.

## Устранение неполадок

| Симптом | Что проверить |
|---|---|
| «Не удалось подключиться к роутеру. Проверьте IP и пароль» | Роутер включён и доступен из сети бота; `ROUTER_HOST` совпадает с адресом веб-интерфейса; `ROUTER_PASSWORD` — пароль администратора |
| «Роутер отклонил авторизацию» | Неверный `ROUTER_PASSWORD` или `ROUTER_USERNAME` (по умолчанию `admin`) |
| HTTPS с самоподписанным сертификатом | Поставьте `ROUTER_VERIFY_SSL=false` |
| Бот молчит в ответ на команды | Ваш ID не в `ADMIN_IDS` — узнайте его через `/myid` у @userinfobot и добавьте |
| Ошибка конфигурации при старте | Заполните `.env` по шаблону `.env.example` |

## Дисклеймер

Проект использует стороннюю библиотеку `tplinkrouterc6u` для взаимодействия с роутером.
Работа конкретных прошивок Archer C80 может отличаться; при unexpected-ответах роутера бот
логирует детали в `bot.log` и возвращает пользователю понятное сообщение об ошибке.
